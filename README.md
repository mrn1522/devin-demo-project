# Flappy Bird

A Flappy Bird clone built with Vite, TypeScript, and the Canvas API.

## Prerequisites

- Node.js 24

## Commands

```bash
npm install
npm run dev
npm run build
npm test
npm run lint
npm run format
```

## Roadmap

1. Scaffold
2. Core loop & bird
3. Pipes & scoring
4. Polish (HUD, overlays, difficulty ramp, synthesized audio)
5. Mobile & GitHub Pages deploy
